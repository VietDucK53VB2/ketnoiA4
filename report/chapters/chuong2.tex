\subsection{Diễn giải từng bước}

\begin{enumerate}
    \item Camera Stream gọi endpoint \Code{POST /api/v1/vision/detect} với JSON gồm \Code{camera_id}, \Code{frame_url} và \Code{timestamp}.
    \item FastAPI validate request body qua schema \Code{VisionDetectRequest}. Nếu thiếu trường hoặc sai kiểu, service trả về lỗi 422.
    \item Hàm \Code{_fetch_image_bytes()} dùng HTTP client để tải ảnh từ \Code{frame_url} với timeout 15 giây.
    \item Ảnh được nhận dưới dạng bytes, sau đó được giải mã bằng OpenCV.
    \item Hàm \Code{analyze_image()} quyết định chạy YOLO hoặc fallback sang mock AI.
    \item Kết quả \Code{DetectionResult} được lưu vào \Code{DETECTION_STORE} bằng khóa \Code{detection_id}.
    \item Kết quả được serialize thành JSON và trả về cho Camera Stream.
\end{enumerate}

\section{Thiết kế Data Models}

\subsection{VisionDetectRequest - schema đầu vào}

Request đầu vào gồm ba trường chính: mã camera, URL ảnh và thời điểm ghi nhận frame. Trường \Code{frame_url} hỗ trợ thêm alias \Code{image_url} để tương thích với endpoint cũ.

\subsection{DetectionResult - schema đầu ra chính}

Kết quả trả về gồm mã detection, mã camera, URL ảnh, timestamp, trạng thái phát hiện bất thường, độ tin cậy, thông tin đối tượng và chế độ model. Trường \Code{finding} có thể rỗng nếu ảnh không có đối tượng đáng chú ý.

\subsection{Discriminated Union - PersonFinding và ObjectFinding}

Pydantic Discriminated Union cho phép service tự động chọn schema dựa trên \Code{finding_type}. Nếu giá trị là \Code{person}, dữ liệu được parse thành \Code{PersonFinding}; nếu giá trị là \Code{object}, dữ liệu được parse thành \Code{ObjectFinding}.

\subsection{CoreCameraEvent - adapter cho Core Business}

Adapter chuyển đổi ngôn ngữ dữ liệu của AI Vision sang ngôn ngữ nghiệp vụ của Core Business. Đây là ví dụ điển hình của Adapter Pattern trong hệ thống microservices.

\subsection{GET /model}

\subsection{POST /api/v1/vision/detect}

Đây là endpoint quan trọng nhất, được Camera Stream gọi khi phát hiện chuyển động. Request gồm \Code{camera_id}, \Code{frame_url}, \Code{timestamp}; response trả về \Code{DetectionResult}.

\begin{verbatim}
{
  "camera_id": "cam-gate-01",
  "frame_url": "https://ultralytics.com/images/bus.jpg",
  "timestamp": "2026-05-02T09:10:00"
}
\end{verbatim}

\begin{verbatim}
{
  "detection_id": "det-a1b2c3d4e5f6",
  "camera_id": "cam-gate-01",
  "anomaly_detected": true,
  "confidence_score": 0.87,
  "model_mode": "yolo"
}
\end{verbatim}

\subsection{GET /api/v1/vision/detections/\{detection\_id\}}

Endpoint này tra cứu kết quả đã lưu. Nếu không tìm thấy \Code{detection_id}, service trả về lỗi 404.

\subsection{POST /api/v1/events/camera}

Endpoint adapter nhận \Code{VisionDetectRequest}, chạy detection, sau đó chuyển đổi kết quả thành \Code{CoreCameraEvent}. Endpoint này dành cho Core Business khi cần nhận event đã chuẩn hóa.

\subsection{POST /analyze và POST /analyze/mock}

Hai endpoint legacy được giữ lại để tương thích ngược. \Code{/analyze} nhận input kiểu cũ, còn \Code{/analyze/mock} luôn trả về kết quả mock để demo nhanh.

\section{Mã nguồn tiêu biểu và giải thích}

\subsection{Luồng xử lý chính - run detection}

Hàm \Code{_run_detection()} là orchestrator chính. Hàm này normalize input, tải ảnh, chạy AI inference, build response và lưu kết quả vào bộ nhớ tạm.
