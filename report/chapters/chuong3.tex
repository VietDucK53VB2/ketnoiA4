\section{Phân tích chi tiết các module}

\subsection{app/vision.py - AI Engine}

Module này chịu trách nhiệm toàn bộ logic AI. Nó có các thành phần chính:

\begin{itemize}
    \item Fallback Mock AI: `_mock_result()`.
    \item Lazy-load model: `_load_model()`.
    \item YOLO inference: `_run_yolo()`.
    \item Entry point: `analyze_image()`.
\end{itemize}

\subsection{app/main.py - API Server}

`main.py` là "mặt tiền" của service. Mã nguồn gồm:

\begin{itemize}
    \item Pydantic models: `VisionDetectRequest`, `DetectionResult`, `CoreCameraEvent`, `ProblemDetails`.
    \item Helper functions: `_problem`, `_fetch_image_bytes`, `_build_finding`, `_store_detection`, `_map_to_core_camera_event`, `_run_detection`.
    \item Dashboard HTML template.
    \item Route handlers cho 7 endpoint.
\end{itemize}

\subsection{test_api.py - Smoke Test Automation}

Script smoke test tự động kiểm tra:

\begin{enumerate}
    \item Health check.
    \item Model status.
    \item Main detection.
    \item Lookup by detection_id.
    \item Mock demo.
\end{enumerate}

\section{Đóng gói Docker}

\subsection{Dockerfile}

Dockerfile sử dụng `python:3.11-slim`, cài dependencies từ `requirements.txt`, copy toàn bộ mã nguồn và chạy Uvicorn trên cổng 8000. Thiết kế này khá gọn và phù hợp với demo học phần.

\subsection{docker-compose.yml}

Compose file khai báo service `ai-vision`, expose port `8000:8000`, đặt `restart: unless-stopped` và gắn `container_name: ai-vision-service`.

\subsection{Kiểm tra container đang chạy}

\begin{verbatim}
$ docker compose ps
NAME STATUS PORTS
ai-vision-service Up 2 minutes 0.0.0.0:8000->8000/tcp

$ curl http://localhost:8000/health
{"status":"ok","service":"ai-vision-service"}

$ curl http://localhost:8000/model
{"model_name":"yolov8n.pt","ultralytics_available":true,"loaded":true,"mode":"yolo"}
\end{verbatim}

\subsection{Phân tích kết quả}

\begin{itemize}
    \item Tốc độ inference chấp nhận được cho bài toán giám sát không yêu cầu real-time nghiêm ngặt.
    \item Với ảnh rõ nét, confidence đạt mức tốt.
    \item Khi URL không tồn tại, service timeout sau 15 giây và chuyển sang mock.
    \item Mock mode phản hồi rất nhanh, phù hợp cho demo.
\end{itemize}
